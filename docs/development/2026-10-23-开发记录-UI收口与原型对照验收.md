# UI 收口与原型对照验收

日期：2026-10-23。范围：瓷白＋克莱因蓝主题下的首页、投资、账本、记一笔及公共组件。业务规则、金额计算、接口、后端和数据库结构未改动；本轮改动保留在工作区，未提交、推送或部署。

> 后续状态（2026-10-24）：本轮改动已提交为 `5d300e4`，并随功能分支合入 `main`、推送；仍未部署。

## 1. 界面变化

| 调整前 | 调整后 | 目的 |
| --- | --- | --- |
| 投资页并排展示四个操作、搜索排序和七个指标选项 | 交易菜单、搜索／指标设置、待处理交易各有独立展开入口；筛选收起后仍显示范围及清除入口 | 优先展示持仓和收益，保留全部已有操作 |
| 基金卡片重复展示金额与指标 | 390px 起采用紧凑列式，320px 将名称与三指标分行，A/C 与平台明细仍可展开 | 便于比较，避免小屏金额断行 |
| 账本先展示视图切换和历史入口，再展示周期汇总 | 周期与收支汇总前移，筛选默认收起；分类恢复 SVG 图标 | 流水和金额成为页面主体 |
| 首页图表高 220px，口径说明常驻且重复 | 图表恢复 152px，说明收进“统计口径”，资产区提前；选点同步上方日期与金额 | 接近已确认原型的首屏密度 |
| 记账分类使用首字，复杂核对入口直接外露 | 五列分类图标，核对及历史入口收进“更多选项” | 保持快速记账路径清楚 |
| 各页空状态和部分返回按钮不一致 | 新增 AppIcon、PageHeader、EmptyState，统一 back-link、图标按钮和展开控件样式 | 消除浏览器默认按钮，形成一致的界面语言 |

原型和已确认截图保持原样，作为对照依据。桌面继续采用 430px 手机画幅。

## 2. 自动化与独立审查

- 前端 79 项测试通过，类型检查与生产构建通过，`git diff --check` 通过。
- 在原有 75 项基础上增加四项回归：空状态单一行动、图表选点事件、收起筛选后的范围提示、Enter 展开更多选项不触发保存。
- Enter 回归先在修改前复现：已有金额时，summary 收到 Enter 会调用保存；修复后保留 summary 和链接原生键盘行为，测试通过。金额计算、校验和保存服务不变。
- 独立只读审查指出的 ECharts 实际事件字段、收起搜索的范围歧义、切换趋势时旧选点残留均已修复并复核。
- 构建仍输出大于 500kB 的分包提示；本轮没有调整依赖或打包策略。
- 未重跑后端测试；本轮没有后端、接口类型、数据迁移或金融计算代码变更。

## 3. 浏览器验收

使用当前 Vue 页面与 Chromium，不以组件测试代替浏览器结果。

| 环境 | 覆盖及结果 |
| --- | --- |
| 现有开发前端／API `localhost:5173` | 首页部分资产、投资无持仓、账本无记录、记账页及公共样式检查；没有提交业务数据 |
| 独立前端 `127.0.0.1:5175` 与只读演示数据服务 | 使用虚构资产与现有组件测试中的基金样本，补验完整数据、长名称、缺行情、筛选无结果、交易菜单和待确认入口 |
| 320／390／430px | 四个重点页面均无横向溢出；320px 投资金额不再拆行；图标和键盘可用 |
| 桌面浏览器 | 页面仍为 430px 手机画幅，无横向溢出 |

具体交互：

- 投资交易菜单可打开原有买入表单，取消后关闭；待处理交易可进入确认份额表单并取消。
- 搜索一只基金并收起设置后，顶部和设置入口仍标明搜索范围；清除恢复全部范围。
- 账本搜索无结果显示统一空状态，清除后恢复列表；图表及分类排行正常展示。
- 记账选择购物，键盘输入 `12.3` 后可完成；Enter 展开更多选项后取消返回账本。修复后的该路径网络写请求为 0。
- 实际点击首页趋势图：上方读数由 `2026-10-23 / 286,400.00` 更新为所选点 `2026-10-06 / 279,713.00`；切换范围后恢复最新点。金额仅为演示数据。
- 缺行情显示“行情待补”，不添加人民币符号，不展示伪造的 0 金额。

演示服务只接受 GET，不连接数据库；首次复现 Enter 缺陷时的误提交被 405 拒绝。验收结束后停止该演示服务和独立前端，保留现有开发服务。
