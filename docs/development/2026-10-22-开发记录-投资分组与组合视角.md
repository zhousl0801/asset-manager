# 投资分组与组合视角

日期：2026-10-22。范围：投资分组模型与维护、基金按名称归集、同基金 A/C 类与多平台展开、持仓 / 收益 / 交易 / 定投四个视图、三项指标和搜索排序。

## 1. 背景

产品要求投资页提供「全部基金 + 用户自定义分组」的组合视角，切换分组后顶部金额、持仓、收益、交易和定投使用同一范围；同一基金的 A/C 类分别保存份额与净值，类别内跨平台可汇总份额但保留平台成本和持仓；每个基金归入一个主分组（§6.1–6.3、AC07–AC09）。此前基金页只有按持仓行平铺的列表，没有分组、基金级汇总或视图切换。

## 2. 数据模型与迁移

新增 `FundGroup`：

| 字段 | 含义 |
| --- | --- |
| `Name` | 分组名称，最长 20 个字符，同账本内唯一 |
| `SortOrder` | 分组显示顺序，新建时追加到末尾 |
| `Version` | 并发标记 |

`FundPosition` 增加可空 `FundGroupId` 外键，删除分组时数据库将持仓归属置空。第 12 个迁移 `AddFundGroups` 创建 `fund_groups` 表并增加 `fund_positions.fund_group_id` 与索引；迁移不修改已有持仓、成本、份额或流水。

分组按基金名称归集：同一账本中名称相同（去除首尾空格后完全一致）的持仓视为同一只基金。调整某一持仓的分组时，服务在同一事务内移动该基金全部 A/C 类和各平台持仓，避免同一基金跨分组。基金身份不按代码归集，因为 A/C 类通常使用不同基金代码。

## 3. 后端接口与规则

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/ledger/fund-groups` | 读取分组、基金数、持仓数和已确认估值 |
| POST | `/api/ledger/fund-groups` | 新建分组；重名返回 409 |
| PUT | `/api/ledger/fund-groups/{id}` | 分组改名；重名返回 409 |
| DELETE | `/api/ledger/fund-groups/{id}` | 删除分组，组内基金回到未分组 |
| PUT | `/api/ledger/fund-groups/positions/{positionId}` | 调整基金分组；`groupId` 为 `null` 表示未分组 |

基金总览 `GET /api/ledger/funds` 新增：

- `funds`：按基金名称归集的基金列表，包含估值、成本、持有收益、已实现收益、买入待确认、赎回待到账、平台数、最新净值日期和覆盖状态。
- `funds[].classes`：按份额类别分组；每类分别返回份额、成本、估值、收益、类别净值（各平台净值不一致时为 `null`）和平台持仓。
- `funds[].classes[].platforms`：平台持仓行，保留平台、代码、类别、份额、成本、净值、估值、收益和行情有效性。
- `groups`：分组 ID、名称、排序、基金数、持仓数和已确认估值。

`funds` 的基金值不含未确认的买入或待到账金额；`assetValue` 才包含该基金的买入待确认和赎回待到账。基金级不返回跨类别合计份额，也不平均不同类别净值。分组变更属于元数据操作，不携带 `requestId`，不生成资产流水，不改变总资产。

## 4. 前端组合视角

- 新增分组胶囊：全部、各自定义分组和未分组；胶囊显示基金数。切换后顶部总金额、成本、收益、待确认 / 待到账、基金列表、交易和定投一起过滤。
- 新增「持仓 / 收益 / 交易 / 定投」四个视图。持仓展示基金估值；收益展示持有收益和收益率；交易复用活动列表并按当前范围过滤；定投读取统一计划接口，只显示当前范围内基金关联的定投计划。
- 基金卡片按基金汇总，展开后先列 A/C 类，再列各平台持仓；类别内汇总份额，类别之间不合并。
- 支持按名称、代码或平台搜索，按持仓价值、持有收益、收益率或名称排序。
- 指标选择最多三项，默认持仓价值 / 持有收益 / 收益率，可选成本、占比、平台数和在途金额；选择保存在浏览器本地存储，只影响展示。
- 「管理」底部弹层支持新建、改名和删除分组；基金展开后可直接调整所属分组。删除分组只把基金移到未分组。

## 6. 边界

- 基金身份按名称完全一致归集；同名但实际不同的基金目前会被视为同一只，需要用不同名称区分。
- 分组暂不支持拖拽排序、层级分组和颜色；新建顺序即显示顺序。
- 「收益」视图当前展示持有收益、收益率和已实现收益，不包含收益走势和收益日历；按净值日的区间收益属于下一轮。
- 交易视图沿用最近 200 条活动，范围过滤后可能少于 200 条；更早记录暂不能单独翻页。
- 定投视图只读展示并跳转统一计划页，不在投资页新建或编辑计划。
- 分组操作不接入 `requestId` 回执；它是无资金影响的元数据变更，失败时刷新后重试。
