# 2026-10-22 开发记录：G2 积存金卖出待到账

本轮完成 G2 在途交易闭环的最后一项：积存金卖出可选择“已到账”或“待到账”，待到账在确认收款后转入现金。

## 1. 已实现行为

### 卖出收款状态

- `POST /api/ledger/gold/sells` 增加 `settlement`：`received`（默认，已到账）或 `pendingArrival`（待到账）。
- 已到账沿用原行为：减少克数与成本，净回款直接进入现金。
- 待到账：减少克数与成本，净回款计入积存金待到账，现金不变；按净回款与结转成本的差额记录已实现盈亏。
- 待到账卖出不产生现金变动，不能关联现金核对差额。

### 待到账收款

- 新增 `POST /api/ledger/gold/sells/{transactionId}/arrival`，录入到账金额、到账日期和备注。
- 到账金额必须与待到账金额一致；不一致时要求先更正卖出记录，不静默抹平差额。
- 到账只把待到账转入现金，不再次确认盈亏，也不计入生活收入；同一笔卖出只能到账一次。
- 到账日期不得早于卖出日期；到账请求使用 `requestId` 幂等，重复提交返回首次结果。

### 资产口径与历史

- 积存金资产 = 持有克数 × 有效报价 + 卖出待到账资金；待到账不计入持有克数与持仓成本。
- 首页、积存金页、历史页和现金页展示待到账金额与到账流水；现金页标题为“积存金卖到账”。
- 待到账卖出和到账均为独立业务事实，按业务日期和同日顺序重放。
- 已到账的卖出不能直接更正或撤销，需先撤销到账；到账金额在历史更正中必须与卖出待到账金额一致。
- 撤销待到账卖出会恢复克数与成本、移除待到账；撤销到账会恢复待到账并减少现金。

## 2. 接口与数据变化

| 项目 | 变化 |
| --- | --- |
| `AssetTransactionKind` | 新增 `GoldSellPending`、`GoldSellArrival`；历史 `GoldSell` 保留为已到账卖出 |
| `POST /api/ledger/gold/sells` | 请求新增 `settlement: received \| pendingArrival`，默认 `received` |
| `POST /api/ledger/gold/sells/{id}/arrival` | 新增到账接口，请求为 `amount/businessDate/note/requestId` |
| `GET /api/ledger/gold` | 返回 `pendingArrivalAmount`、`pendingArrivals`；`value` 包含待到账 |
| 历史接口 | 待到账卖出和到账进入同一重放与预览 |
| 首页 / 现金页 | 积存金金额包含待到账；到账流水标为“积存金卖到账” |

本轮复用第 8 个迁移的 `linked_transaction_id`，没有新增数据库迁移。暂无 `fee` 字段需求的积存金变动仍沿用现有金额口径。
