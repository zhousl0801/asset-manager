日期：2026-10-30
状态：P0 / P1 / P2 已完成，进入可用状态

## 1. 范围

本轮按已确认口径新增 A 股股票模块：

- 仅 A 股：沪市、深市、北交所
- 人民币计价
- 多持仓，按 `ledger_id + market + code` 唯一
- 买入、卖出、录入持仓、核对持仓
- 东方财富行情刷新，保存最新价与昨收
- 今日盈亏按资金流调整后的当日损益计算
- 接入资产总览、资产分布、资产覆盖、趋势、月度变化、行情状态和备份
- 历史更正 / 撤销沿用现有业务事实重放

本版不做：港股 / 美股、多币种、券商账户、分红、送转、配股、融资融券、自动定投。

## 2. 设计文档

- [股票模块设计规格](../design/股票模块-设计规格-2026-10-30.md)
- 今日盈亏公式：

```text
今日盈亏 = 当前行情时点市值
         - 昨收时点市值
         - 今日买入实际扣款
         + 今日卖出净到账
```

费用已包含在买卖金额中；当日有建仓或持仓核对时，该持仓今日盈亏显示为空。

## 3. 后端实现

### 3.1 领域

- `AssetType.Stock`
- `StockMarket`
- `StockPosition`
- 新交易类型：`StockOpening`、`StockBuy`、`StockSell`、`StockQuote`、`StockCorrection`
- `AssetTransaction.StockPositionId` 与统一 `PositionId`
- `PriceObservation.StockPositionId`
- `Ledger.StockNotHeld`

### 3.2 交易规则

- 买入：`Amount = 成交金额 + 费用`，现金减少，成本增加
- 卖出：`Amount = 成交金额 - 费用`，现金增加，按比例结转成本
- 首次买入可自动建立持仓
- 卖出不能超过该业务日期时点持股
- 录入 / 核对持仓不改变现金
- 股票行情只更新估值，不改变成本

### 3.3 历史与总资产

- `BusinessFact.PositionId` 统一映射基金 / 股票持仓
- `LedgerReplayData` 与 `ReplayResult` 增加股票持仓
- `LedgerReplayCalculator` 支持股票建仓、买入、卖出、核对、行情
- `LedgerHistoryRebuilder` 恢复股票投影，保留昨收缓存
- `LedgerService`、`TrendService`、`MonthChangeService`、`AssetCoverage` 全部纳入股票
- 股票行情加入 `QuoteRefreshScope.Stocks`、`QuoteRefreshService`、定时任务和状态页

### 3.4 今日盈亏

- 以行情日期为基准，取 `PreviousCloseDate` 或前一 A 股交易日
- 使用昨收时点持股和行情时点持股，避免行情落后时把后续交易算进旧价格
- 区间内存在 `StockOpening` / `StockCorrection` 时置空
- 缺少昨收且昨收时点有持股时置空
- 今日首次买入退化为“市值 - 实际扣款”
- 非交易日按最近行情日展示
- 组合存在不完整持仓时返回 `TodayProfitComplete = false`，前端标注“估算”

### 3.5 行情

- `IStockQuoteProvider`
- `EastmoneyStockQuoteProvider`
- 搜索接口与行情接口均使用公开接口，来源记为 `eastmoney`
- 行情日期、最新价、昨收、来源写入持仓缓存
- 刷新失败保留最近有效值和昨收，并记录失败原因

### 3.6 备份

- 备份格式升到 `v2`，恢复兼容 `v1`
- 增加 `stockPositions`、`assetTransactions.stockPositionId`、`priceObservations.stockPositionId`、`ledger.stockNotHeld`
- 恢复前用历史重放校验股票数量、成本、已实现收益、最新价和行情日期

## 11. 修复：股票行情刷新失败

### 11.1 现象

录入 159915 持仓后刷新行情失败，持仓里记下 `lastQuoteError: An error occurred while sending the request.`，
最新价停在录入时手填的日期上。

### 11.2 定位

- 直接 curl 东方财富行情接口：`push2.eastmoney.com` TLS 握手正常但服务器**空响应**（`Empty reply from server`），
  `1.push2` / `7.push2` / `82.push2` 与 http 版本同样空响应
- 同一时刻 `push2delay.eastmoney.com` 正常返回同结构数据（`f43` / `f57` / `f58` / `f59` / `f60` / `f86`），
  价格与腾讯行情一致；搜索接口 `searchapi.eastmoney.com` 一直可用
- 结论：不是解析或业务逻辑问题，是行情主站整机不可用，代码只认一个站点

### 11.3 改动

- `QuoteProviderOptions` 新增 `StockFallbackBaseUrl`（默认 `https://push2delay.eastmoney.com/`）
- `EastmoneyStockQuoteProvider` 改为按站点顺序请求：连接失败、超时、非 2xx 都换下一个站点；
  全部失败时抛出「股票行情服务暂时无法连接，请稍后重试。」，不再把 .NET 原始异常文案透出到页面
- 新增两个单元测试：主站抛 `HttpRequestException` 时降级成功、两个站点都失败时返回友好错误

### 11.4 验证

- 后端 333 项（315 通过 + 18 项真实 PostgreSQL 跳过）
- 真实账本持仓 `159915`：批量刷新由失败转为成功，最新价 2.435、行情日 2026-10-30、昨收 2.535（2026-10-29），
  今日盈亏 −1000、持有盈亏 −3370，`lastQuoteError` 清空
