日期：2026-10-23。范围：首页总览、资产页、底部导航、趋势图与本月变化口径；新增“不持有 / 覆盖确认”持久化和“同口径月度变化”计算。本轮改动未提交、未推送、未部署。

> 后续状态（2026-10-24）：本轮改动已提交为 `f8fb4c8`，并随功能分支合入 `main`、推送；仍未部署。

## 1. 口径变化

| 项目 | 调整前 | 调整后 | 说明 |
| --- | --- | --- | --- |
| 首页标题 | “部分资产合计 / 总资产”混用 | “已记录资产”，确认覆盖后才显示“总资产” | 完整记录之前不出现“总资产” |
| 本月变化 | 新增资产计入变化，一天可显示“涨 11 万” | 同口径变化：只比较月初和今天都已记录的类别 | 新增记录单独标注，不计入变化 |
| 变化分解 | 生活结余 / 公积金缴存 / 投资盈亏 / 核对差额 | 市值变动 / 净存入·转账 / 新增记录 | 现金和公积金只称余额变化 |
| 资产完整度 | “4 类资产”固定文案 | “已记录 N 类”，缺失项显示“暂未录入” | 不假设用户持有全部四类 |
| 无法补全 | 无“不持有”状态，缺一类就永远不完整 | 可标记“不持有”，再确认“其他资产均已覆盖” | 覆盖状态落库，可撤销 |
| 趋势 | 画全部已知资产，新录入被画成上涨 | 只累计区间起点已记录的类别，新增记录当天标虚线 | 同口径曲线 |
| 趋势期数 | 近 1 月 / 近 3 月 / 今年 / 全部 | 7 日 / 1 月 / 3 月 / 全部 | 新增 `week` 范围 |
| 历史不足 | 直接画两个点的曲线 | 显示“记录满 7 天后显示趋势”与进度 | 不足 7 天不画线 |
| 图表细节 | 7 条网格线和纵轴标签 | 无纵轴标签，只标最高 / 最低点，拖动显示当日金额 | 减少噪声 |
| 日期 | Hero “统计截至 10-22”，横轴到 10-23 | 统一显示数据更新日 | 消除日期不一致 |

## 2. 后端与数据

- `ledgers` 增加 `fund_not_held`、`provident_fund_not_held`、`gold_not_held`、`coverage_confirmed` 四个布尔列，迁移 `AddAssetCoverage` 为第 13 个迁移；开发库已在备份后应用。
- 新增 `PUT /api/ledger/coverage`：保存“不持有”和覆盖确认，返回最新账本概览。有持仓的资产不允许标记为不持有；仍有未录入且未标记的资产时不允许确认。
- `MonthChangeService` 改为同口径计算：比较月初基线（账本起始日晚于月初时视为无可比基线）与今天，只累加两侧都已记录的类别；新增类别计入 `addedRecords` 并单独提示；`assetChanges` 返回每类的变化和“本月新增”标记。
- `TrendService` 新增 `week` 范围和每类“当天是否已记录”的标记（`hasCash/hasProvident/hasFunds/hasGold`），前端据此判断同口径曲线和新增记录日。
- 存在性判断改用持仓覆盖起始日（`CoverageFrom`），避免“持仓行已存在”被误判为该日已记录。
- 积存金自动报价刷新不再写入“交易与持仓记录”列表（行情观测仍保留，用于历史估值和行情溯源）。

## 3. 前端与原型

- 新增 `AssetDistribution` 组件：比例条 + 统一行结构（色点、金额、占比、类型信息、较上月），首页和资产页共用。
- 新增资产页 `/assets`：已记录资产金额、覆盖确认卡片、四类资产的录入 / 不持有操作。
- 首页重写：头部（品牌 + 历史 / ＋）、已记录资产、同口径本月变化与分解、趋势区、资产分布，本月收支和自动记账保留在下方。
- 底部导航由五项（含中间 ＋）改为“总览 / 资产 / 账本 / 我的”四项；记一笔入口移到头部 ＋ 的操作面板。
- 原型（`prototype/`）首页同步改造：同名标题、同口径分解、分布列表、趋势无纵轴标签并标注最高 / 最低点、四项导航；演示数据仍为虚构值。

## 5. 已知限制

- 同口径比较按资产类别进行；同类资产在区间内新增持仓时，计入该类别的变化，不单独标记。
- 覆盖确认是用户声明，不校验账本外是否存在其他资产；撤销确认后首页立即回到“已记录资产”。
- 趋势“满 7 天”按账本起始日计算，历史补录不会缩短该等待期。
