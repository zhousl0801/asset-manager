# 投资收益走势与收益日历

日期：2026-10-22。范围：按净值披露日归属的基金收益走势、区间盈亏、持有收益分列、收益日历和单日明细。

## 1. 背景

产品要求投资页提供本月、近 3 月、今年、全部的收益走势和收益日历，以实际净值日期归属收益；未披露净值显示“未披露”或“—”，不按 0 收益处理；区间投资盈亏与持有收益使用不同名称；缺少区间起点或行情依据时不得生成精确累计收益（§6.5、AC14）。此前基金页只有当前持有收益，没有按日收益或区间盈亏。

## 2. 计算口径

### 2.1 每日已披露收益

- 从 `PriceObservation` 取每个持仓的实际有效日期和净值，只使用未撤销、未失效的观测。
- 每个持仓的当日收益 = 当前净值日持仓资产值 − 上一个净值日持仓资产值 − 期间净转入 − 期间持仓核对差额。
  - 持仓资产值包含已确认份额估值、买入待确认和赎回待到账。
  - 期间净转入取资金流入投资资产的业务：买入待确认 / 买入为 `+金额`，赎回到账为 `−金额`；买入确认、赎回申请和赎回确认不产生跨现金转移。
  - 持仓核对差额按更正数量差 × 更正价格扣除；缺少价格时该日收益返回空。
- 同一天披露的持仓收益相加。只披露部分基金或份额类别时，合计只包含已披露项目，并标记 `partial`。
- 未披露净值的日期 `dailyProfit` 返回 `null` 并标记 `notDisclosed`；页面显示“—”，不写 0。累计收益沿用上一个有效值，并在图上和日历说明中标注，不把平线解释为当日 0 收益。
- 同一有效日期的多条净值按最新修订顺序取值；已撤销交易产生的行情观测不参与计算。

### 2.2 区间盈亏

```text
区间盈亏 = 区间期末投资资产 − 区间期初投资资产
         − 区间净转入 − 区间持仓核对差额
```

- 期初取区间开始日前一日；开始日早于账本起始日时取账本起始日收盘，并返回说明。
- 部分基金在区间开始后才建立持仓依据时，`intervalFrom` 后移到所有范围内基金都有依据的日期，并在 `notes` 说明；不把导入起始值伪装成收益。
- 区间收益率以区间期初资产为分母，页面标明“非年化”；不称为年化收益或内部收益率。

### 2.3 持有收益与已披露累计收益

| 名称 | 口径 | 用途 |
| --- | --- | --- |
| 持有收益 | 当前已确认持仓估值 − 剩余成本 | 当前持仓盈亏 |
| 区间盈亏 | 区间期末资产 − 期初资产 − 净转入 − 核对差额 | 指定区间投资结果 |
| 已披露累计收益 | 区间内各净值日可计算收益之和 | 走势图累计线，可能因未披露或依据不足而不完整 |

三者分别命名，不能相加后互相替代；买入待确认和赎回待到账计入区间资产，但不计入持有收益的成本与收益。

## 3. 后端接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/ledger/funds/returns` | `range=month\|quarter\|year\|all`；支持 `groupId` 或 `ungrouped`；返回区间汇总、每日点、基金汇总和说明 |
| GET | `/api/ledger/funds/returns/day` | 指定 `date`，返回当日合计、各持仓收益和未披露原因 |

`FundReturnDto` 关键字段：

- `from` / `to` / `intervalFrom`：走势区间与区间盈亏实际起算日。
- `openingAssetValue` / `closingAssetValue` / `netTransfer` / `reconciliationDifference`：区间盈亏的组成。
- `intervalProfit` / `intervalRate` / `holdingProfit` / `holdingRate`：分列命名。
- `points[]`：日期、基金资产值、当日收益、累计收益、披露基金数、覆盖持仓数、状态（`complete` / `partial` / `notDisclosed` / `insufficient`）。
- `funds[]`：每只基金的区间值、区间盈亏、持有收益、已披露累计收益、披露天数和最近净值日期。
- `notes[]`：覆盖范围、未披露、区间起算和核对依据说明。

单日接口 `FundReturnDayDto` 返回 `totalProfit`、覆盖数量、状态和每个持仓的估值、净值、当日收益、披露状态及原因；未披露持仓的 `dailyProfit` 为 `null`。

实现：`FundReturnService`、`FundReturnDto`、`FundReturnsController`；复用 `LedgerReplayCalculator`、`BusinessFact` 和 `PriceObservation`，不新增表或迁移。

## 4. 前端

- 投资页「收益」视图新增 `FundReturnsPanel`：
  - 区间切换：本月 / 近 3 月 / 今年 / 全部。
  - 顶部同时展示“区间盈亏”“持有收益”“区间收益率”，副标题分别说明口径和是否有在途。
  - 区间说明显示覆盖天数、净值披露天数、起止日期和 `notes`。
- 新增 `FundReturnChart`：当日收益柱状图（正红负绿）+ 已披露累计收益折线；未披露日柱子为空、累计值沿用上一有效值，tooltip 标明“未披露 / 部分披露 / 覆盖持仓数”。
- 收益日历按周一至周日排列，默认当前月，可在走势区间内前后切换。每个日期显示当日收益或“—”，正负背景区分；点击日期打开单日明细。
- 单日明细展示当日合计、可计算持仓数，以及各基金 / 份额类别 / 平台的估值、净值、当日收益和披露状态；未披露显示“—”和原因。
- 分组切换时收益接口携带 `groupId` 或 `ungrouped`，区间汇总、走势、日历和单日明细使用同一范围。

## 6. 边界

- 每日收益只在净值披露日计算；没有新净值的日期不生成 0 收益。若持仓在两次净值披露之间发生交易，交易影响合并计入下一次披露日的收益，并按净转入扣除。
- 区间盈亏对缺少完整起始依据的基金不推测；`intervalFrom` 后移并在说明中标注，无法可靠确定时返回 `null`。
- 已披露累计收益是“可计算部分之和”，与区间盈亏可能不同；页面已分别命名，不宣称等同于区间投资回报。
- 收益日历默认显示走势区间内的月份；区间外的月份不可切换。
- 未实现基金经理比较、基准、回撤、年化收益或收益归因；截图识别与导出备份仍在后续范围。
