# 2026-10-22 开发记录：真实行情接入

本轮在 G2 在途交易闭环之后，接入服务端行情获取：基金净值来自天天基金公开接口，积存金使用上期所黄金连续参考价。行情失败时保留最近有效值，并持久化失败状态。

## 1. 已实现行为

### 基金净值

- 新增 `POST /api/ledger/funds/{positionId}/quote/refresh`，按基金代码从天天基金公开接口获取最近已披露净值。
- 净值仍作为 `FundQuote` 业务事实保存，记录净值有效日期、来源和取得时间；同一净值 / 日期 / 来源重复获取不会重复写入。
- 未填写基金代码时明确提示，不猜测代码；手动更新净值入口保留。

### 积存金参考报价

- 新增 `POST /api/ledger/gold/quote/refresh`，获取上期所黄金连续（人民币/克）参考价。
- **该报价是期货参考价，不是平台积存金报价**；页面明确标注来源，手动录入平台报价的入口保留，不把参考价宣称为平台成交价。
- 报价更新只影响估值和持有盈亏，不改变现金、克数和成本。

### 来源、失败状态与历史

- `asset_transactions` 新增 `quote_source`，行情事实保留来源；`price_observations` 使用同一来源。
- `fund_positions` 和 `gold_holdings` 保存最近一次获取时间、来源和错误；失败时继续展示最近有效值并显示失败原因。
- 行情服务返回 502 时，页面保留原表单和最近有效值；刷新页面后仍能看到最近一次失败状态。
- 手动录入净值 / 报价会记为 `manual` 来源并清除上一次失败状态。
- 行情来源和有效日期继续进入历史重放、历史核对与行情来源列表。

## 2. 接口、配置与数据变化

| 项目 | 变化 |
| --- | --- |
| `POST /api/ledger/funds/{positionId}/quote/refresh` | 获取并保存基金净值；返回是否更新、来源、净值、有效日期和获取时间 |
| `POST /api/ledger/gold/quote/refresh` | 获取并保存黄金参考报价；返回是否更新、来源、报价、有效日期和获取时间 |
| 行情失败 | 返回 502，最近有效值不变，失败状态写入持仓 |
| `quote_source` | 行情事实来源，最长 40 字符 |
| `last_quote_attempt_at` / `last_quote_source` / `last_quote_error` | 基金持仓和积存金持仓的最近获取状态 |
| 配置 | `QuoteProviders:FundBaseUrl`、`QuoteProviders:GoldBaseUrl`、`QuoteProviders:TimeoutSeconds`，无凭据 |

第 9 个迁移为 `20261022062840_AddQuoteSourcesAndSyncStatus`，只增加列，不重写已有行情记录；既有行情来源保持原样。

## 4. 数据源与边界

- 基金净值来自天天基金公开接口，取最近已披露净值；不保证实时，也不保证接口长期可用或字段不变。
- 积存金使用上期所黄金连续期货参考价，仅用于估值参考，不是任何平台的积存金买卖报价；平台实际报价仍应手动录入。
- 本轮未接入行情失败重试队列、定时刷新或批量刷新；页面按需获取。
- 未配置 API 密钥，也不绕过数据源授权或访问限制；接口不可用时明确显示失败，不生成推算值。
- 真实 iPhone、跨浏览器、读屏和 PWA 安装 / 升级验收仍未执行。
