# 分类维护与账本图表

日期：2026-10-22。范围：账本分类模型与维护页、默认分类迁移、收支统计接口，以及账本明细 / 图表切换、日 / 月 / 年汇总和分类排行。本记录在提交 `fa9401f` 之后补写，用于同步文档与代码状态。

## 1. 背景

产品设计要求账本支持用途分类、分类新增 / 编辑 / 排序，并要求已有记录引用的分类停用后仍可展示和统计（§5.1、§5.2）；同时要求日 / 月 / 年图表、周期总额、日均和分类排行（§5.3、AC06）。此前分类是固定默认列表，账本只有明细列表，没有统计视图。

## 2. 数据模型与迁移

新增 `EntryCategory`：

| 字段 | 含义 |
| --- | --- |
| `Kind` | 收入或支出；两个方向的分类互不混用 |
| `Name` | 分类名称，最长 20 个字符 |
| `SortOrder` | 同一方向内的显示顺序 |
| `IsActive` | 是否可用于新记账；停用不删除历史 |
| `SystemKey` | 系统保留标识，当前为 `salary` 和 `other-income` |
| `Version` | 并发标记 |

- 账本初始化时通过 `EntryCategoryDefaults` 建立 15 个支出分类和 3 个收入分类；工资使用 `salary` 系统标识，供自动记账计划取用。
- 收支记录仍以 `Kind + Category` 名称关联分类，不改为外键。分类改名时在同一事务内批量更新该账本、该方向、原名称下的全部历史收支，记录类型不变。
- 第 11 个迁移 `AddEntryCategories` 创建 `entry_categories` 表，为已有账本补入默认分类，并把历史记录中出现过、但不在默认列表中的分类按原方向和名称补建，避免升级后旧记录引用不到分类。
- 迁移不删除或改写已有收支金额、日期和方向。

## 3. 后端接口与规则

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/ledger/categories` | 读取全部收入 / 支出分类，含停用项 |
| POST | `/api/ledger/categories` | 新增分类；同方向重名返回 409 |
| PUT | `/api/ledger/categories/{id}` | 改名或启停；改名同步历史记录 |
| PUT | `/api/ledger/categories/order` | 重排同方向全部分类，必须完整且不重复 |
| GET | `/api/ledger/entries/stats` | 按 `period`、`anchor` 读取图表与分类排行 |

保存规则：

- 新记账和修改收支只接受存在且启用的分类；修改时若分类未变化，允许保留已停用分类。
- 工资分类不能停用，避免自动记账计划找不到工资分类。
- 分类全量重排按请求中的 ID 顺序写入 `SortOrder`；缺少、重复或跨方向的 ID 返回 400。
- 统计接口返回周期总额、日均、覆盖天数、按日 / 按月的收入支出点、分类金额 / 笔数 / 占比，以及账本起始日晚于周期起点时的覆盖说明。
- 日视图分母为 1；月 / 年视图只统计到今天是已过去部分，未来日期不计入分母。没有记录的已过去日期仍计入覆盖天数。

实现：`EntryCategory`、`EntryCategoryDefaults`、`CategoryService`、`EntryStatsService`、`CategoriesController`；`LedgerEntryService` 增加分类校验，`PlanExecutionService` 改为按系统标识读取工资分类。

## 4. 前端

- 新增分类管理页 `CategoriesView`，从「我的 → 收支分类」进入；支出 / 收入分栏展示，支持新增、改名、启停、上移 / 下移。页面说明改名同步历史、停用只影响新记账。
- 记一笔页面改为从 `/api/ledger/categories` 读取当前启用分类；修改已有记录时保留原分类展示。
- 账本页增加「明细 / 图表」切换。图表页支持收入 / 支出方向、日 / 月 / 年周期、总额、日均、覆盖天数和分类排行；点击分类回到相同周期、相同方向的明细筛选。
- 图表使用 ECharts 柱状图，支出使用克莱因蓝、收入使用深绿色，保持与现有资产趋势图一致的手机宽度布局。

## 6. 边界

- 分类用名称关联收支，不是分类 ID 外键；改名通过同步更新历史记录保持一致，删除分类不提供，只能停用。
- 停用分类不会从历史筛选和统计中消失；已有记录修改时若更换分类，只能选择启用分类。
- 图表统计只覆盖日常收支，不包含公积金缴存 / 提取、投资买卖和余额调整。
- 统计接口不生成快照；每次读取按当前已保存记录计算，历史更正后自然反映到图表。
- 尚未实现自定义分类图标、拖拽排序和分类合并。
