# 首页原型对齐与本月变化

日期：2026-10-22。范围：首页按已确认原型重排、底部主导航与「我的」页、本月变化统计接口。

## 1. 背景

前端 UI 检查时发现首页顶部自行增加了「历史核对与资产回看」「自动记账与执行记录」两个卡片入口，与已确认原型不一致。原型依据：

- [首页高保真原型说明](../../prototype/README.md)。
- [首页手机截图](../design/screenshots/asset-home-v1-mobile.png)与[下半部分](../design/screenshots/asset-home-v1-mobile-bottom.png)。
- [产品设计文档 §4 首页](../product/资产管家-产品设计文档-V1.1.md)。

原型首页顺序为：总资产与本月变化 → 总资产趋势 → 四类资产 → 本月收支 → 近期自动记账。主导航为底部 **总览 / 账本 / ＋记一笔 / 投资 / 我的**；自动记账是页尾区块并带「管理计划 ›」；历史核对不在首页入口。

## 2. 后端：本月变化

新增 `GET /api/ledger/month-change`，返回本月变化及构成：

| 字段 | 含义 |
| --- | --- |
| `from` / `to` | 统计区间；账本本月建立时自起始日起算 |
| `totalChange` | 期末总资产 − 期初总资产；依据不足时为 `null` |
| `livingSurplus` | 本月收入 − 支出 |
| `providentDeposit` | 本月公积金缴存，不含提取 |
| `investmentProfit` | 投资盈亏，按剩余额计算 |
| `reconciliationDifference` | 现金核对差额与持仓核对差额之和 |
| `isComplete` / `notes` | 覆盖是否完整及原因 |

口径：

- 期初取上月最后一日；账本本月才建立时回退到起始日，并返回说明。
- 投资盈亏 = 总变化 − 生活结余 − 公积金缴存 − 核对差额，保证四项之和与总变化一致；买入、赎回到账、公积金提取等跨账户移动净影响为零，不进入任何分项。
- 现金核对差额取未撤销调整的 `Difference`；基金 / 积存金更正按 `(更正数量 − 更正前数量) × 当日报价` 计入核对差额。缺少前序依据或报价时在 `notes` 中说明，差额自然落回投资盈亏。
- 基金、积存金、公积金或行情未覆盖期初 / 期末时，`totalChange` 与 `investmentProfit` 返回 `null`，不填 0，不声明完整总资产。

实现：`MonthChangeService`、`MonthChangeDto`；`LedgerController` 增加路由；`Program.cs` 注册服务。

## 3. 前端：首页与导航

- 首页按原型重排：白色头部（右侧时钟进入自动记账）、总资产与 CNY 标签、本月变化可展开四项构成、趋势卡片（范围切换在卡片内、显示最新日期与金额）、四类资产卡片、本月收支卡片、页尾自动记账预览。
- 自动记账预览优先展示待处理期次，其次按下次到期日展示启用计划；同日多项合并为「N 项自动记账」，说明包含每月日期和计划类型。
- 新增 `AppNav`：底部固定主导航，宽度与手机画幅一致，含安全区适配；`＋` 直接进入记一笔。
- 新增「我的」页：自动记账计划（显示启用数量）、历史核对与资产回看、账本明细。
- 主导航接入全部账本页面（总览、账本、投资、我的、现金、公积金、积存金、历史核对、自动记账）；页面增加 `with-nav` 底部留白，避免内容被导航遮挡。
- 修掉 `RouterLink` 复用 `.back-link` 时的默认下划线。

首页以外的详情页仍保留返回入口；本轮未改动它们的布局。

## 4. 验证

- 后端：`ASSET_KEEPER_TEST_CONNECTION` 指向本机 PostgreSQL 运行，193 项全部通过（含 16 项真实 PostgreSQL）。
- 前端：57 项测试、`npm run type-check`、`npm run build` 通过。
- 浏览器验收：使用独立临时库和第二个前后端实例，录入 8 月起始的现金、基金、公积金与积存金，10 月发生工资、消费、缴存和净值更新。本月变化返回 `13,400.00 = 5,200.00 + 5,200.00 + 3,000.00 + 0.00`，展开、趋势切换、自动记账预览、「我的」和底部导航均正常；截图见 `output/playwright/home-mobile-390.png`、`home-change-expanded.png`、`home-mobile-bottom-verified.png`、`mine-mobile.png`。
- 验收结束已停止临时进程并删除临时库，未改动开发库。

## 5. 边界

- 本月变化要求四类资产和行情覆盖期初；资产刚建立或行情缺失时首页只提示依据不足。
- 账户页头部的「统计截至」仍取现金业务日期，基金净值日期另行在资产卡片或基金页说明。
- 「我的」页只列已上线入口，未实现原型中的收支分类、数据导出恢复和行情状态页。
- 底部导航覆盖除设置页和记一笔之外的全部页面；记一笔保留独立表单结构和键盘布局，不叠加主导航。
