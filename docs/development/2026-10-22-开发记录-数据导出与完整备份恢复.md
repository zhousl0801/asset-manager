# 数据导出与完整备份恢复

日期：2026-10-22。范围：可核对明细 CSV、完整备份 JSON、恢复前校验、确认令牌、事务替换恢复和「我的」数据管理入口。

## 1. 背景

产品要求明细导出可用于核对日期、类型、金额、分类、相关资产和状态；完整备份覆盖起始余额、收支、持仓、交易、成本、在途、分组、行情依据、计划、执行期次及更正历史；恢复前校验格式、关联和重复风险，失败不能破坏当前账本；恢复后保留计划期次去重信息，避免重复记账（§14.2、AC30）。

## 2. 明细导出

`GET /api/ledger/export/details.csv` 输出 UTF-8 BOM CSV，可按 `from` / `to` 过滤。每行是一笔可核对的业务：

| 列 | 说明 |
| --- | --- |
| 日期 | 业务日期 |
| 业务类型 | 日常收入 / 支出、现金核对、各类资产交易、自动计划 |
| 方向 | 收入 / 支出、转入 / 转出、计划类型或核对方向 |
| 金额、现金影响 | 原始金额与对现金的实际影响 |
| 数量、净值或单价、费用 | 基金份额、克数、净值、成交价和费用 |
| 分类或标的 | 收支分类、基金名称 / 类别、积存金 / 公积金说明、计划名称 |
| 状态、来源 | 有效 / 已撤销（含原因）、手动 / 自动 / 业务记录 |
| 关联标识 | `requestId`、持仓、原始交易、现金核对、计划与期次标识 |

收支、现金核对、资产交易和计划期次按日期合并排序；已撤销记录保留并标明状态，不只导出总数。

## 3. 完整备份

`GET /api/ledger/backup` 输出 `asset-keeper-backup` 版本 1 JSON：

- 账本：标识、单例槽、币种、时区、起始日期、版本和 `nextFactSequence`。
- 现金账户：余额、起始余额 / 日期、历史确认标记和版本。
- 公积金账户、积存金持仓。
- 收支分类、收支记录（含请求标识、业务顺序、撤销信息）。
- 现金核对记录（含目标余额、记录差额和撤销状态）。
- 投资分组、基金持仓、资产交易（含关联交易、费用、行情来源和更正类型）。
- 行情观测（有效日期、来源、取得时间、修订顺序、失效标记）。
- 自动计划、执行期次（周期键、计划版本、状态、关联记录）。
- 请求回执（操作、指纹、首次响应和 `beforeJson`），用于更正历史和重复请求恢复。

备份不包含凭据或外部图片。

## 4. 校验与恢复

`POST /api/ledger/backup/validate` 只读校验：

- 格式 / 版本、导出时间、账本字段、币种 / 时区、起始日期。
- 现金、公积金、积存金、基金、交易的金额 / 数量 / 日期范围。
- 引用完整性：分类、分组、持仓、原始交易、行情来源、计划、期次关联记录、现金核对。
- 重复风险：各类 ID、收支 / 资产 / 回执请求标识、分类与分组重名、计划周期键、业务顺序号。
- 用历史重放核对现金、公积金、基金份额 / 成本 / 已实现收益 / 净值和积存金投影；不一致时拒绝恢复。
- 返回备份摘要、当前账本摘要、错误、提示、替换 / 去重说明和确认令牌。当前账本或备份内容变化后令牌失效。

`POST /api/ledger/backup/restore`：

- 必须携带校验令牌；当前账本已存在时必须显式 `replaceExisting=true`。
- 备份账本标识与当前账本不同则拒绝，避免误覆盖其他账本。
- 在关系数据库上使用事务：先删除当前账本数据，再按父到子顺序写入备份；任何失败回滚，当前账本保持不变。
- 恢复采用替换而非追加，请求回执和计划期次按原标识恢复；再次运行计划不会为已执行期次生成新的流水。
- 返回恢复摘要（收支 / 资产 / 计划 / 期次 / 回执 / 行情数量、现金、公积金、基金、积存金、总资产和起始日期）。

实现：`BackupService`、`BackupController`、备份契约与摘要 DTO；`AppDbContext` 直接参与事务和序列化，不新增表或迁移。

## 5. 前端

- 「我的」新增「数据导出与备份」，进入 `/backup`。
- 导出卡片支持可选日期范围，导出明细 CSV 或下载完整备份。
- 恢复流程：选择 JSON → 校验 → 并排显示当前账本与备份摘要 → 查看错误 / 警告 / 替换和去重提示 → 勾选确认替换 → 确认恢复 → 显示恢复结果和返回总览入口。
- 校验未通过时不显示恢复按钮，并明确“不会修改当前账本”；恢复失败保留校验结果和错误。
- 文件只在本机浏览器读取后发送到当前账本服务，不经过第三方。

## 7. 边界

- 备份只支持本应用当前格式版本 1；不做第三方账本格式兼容。
- 只允许恢复同一账本标识；不同账本需先导出/清空或后续提供迁移映射。
- 恢复是整账本替换，不支持只恢复某一日期段或合并两个账本。
- 备份 JSON 未加密，包含完整财务数据；文件保存和传输安全由用户与部署环境负责。
- 当前账本没有认证；云端部署时必须在恢复接口前加入访问控制。
- CSV 是核对用明细，不是可直接回灌的备份；恢复必须使用完整备份 JSON。
- 未实现定时自动备份、云端对象存储或备份加密。
