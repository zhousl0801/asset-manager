# 股票模块设计规格 V1.0

日期：2026-10-30
状态：已确认范围，进入实现

## 1. 范围

### 1.1 本版纳入

- A 股：沪市、深市、北交所
- 场内基金：沪深两市上市、按股票方式交易的 ETF、LOF（与股票同一套交易、成本与行情口径）
- 人民币计价
- 多持仓，按 `市场 + 代码` 唯一
- 买入、卖出
- 录入已有持仓、核对持仓
- 行情刷新与估值
- 今日盈亏
- 资产页、首页、趋势、月度变化、资产覆盖、备份恢复
- 历史更正、撤销与重放

### 1.2 本版不做

- 场外基金（走基金模块）
- 港股、美股、多币种
- 券商账户维度
- 分红、送股、转增、配股
- 融资融券、期权、可转债、打新
- 自动定投、条件单
- 分钟级 K 线
- 券商对账单导入

### 1.3 关键决策

| 事项 | 决策 |
| --- | --- |
| 市场 | 仅 A 股与沪深场内基金 |
| 币种 | CNY |
| 持仓识别 | `ledger_id + market + code` |
| 交易模型 | 直接成交，不做基金式待确认 |
| 成本 | 移动加权平均，和基金一致 |
| 同一股票多券商 | 合并为一个持仓 |
| 今日盈亏 | 按资金流调整后的当日损益计算 |
| 公司行为 | 通过持仓核对处理，不进入今日盈亏 |
| 场内基金 | ETF / LOF 复用股票的买卖、成本、行情与今日盈亏，不单独建资产类型 |

### 2.3 StockPosition

```csharp
public sealed class StockPosition
{
    public Guid Id { get; private set; }
    public Guid LedgerId { get; private set; }
    public StockMarket Market { get; private set; }
    public string Code { get; private set; }
    public string Name { get; private set; }
    public string Currency { get; private set; }
    public decimal Shares { get; private set; }
    public decimal Cost { get; private set; }
    public decimal Price { get; private set; }
    public DateOnly PriceDate { get; private set; }
    public decimal? PreviousClose { get; private set; }
    public DateOnly? PreviousCloseDate { get; private set; }
    public decimal RealizedProfit { get; private set; }
    public DateTimeOffset? LastQuoteAttemptAt { get; private set; }
    public string? LastQuoteSource { get; private set; }
    public string? LastQuoteError { get; private set; }
    public DateTimeOffset UpdatedAt { get; private set; }
    public int Version { get; private set; }

    public decimal Value => decimal.Round(Shares * Price, 2);
    public decimal HoldingProfit => decimal.Round(Value - Cost, 2);
    public decimal? AverageCost => Shares > 0 ? decimal.Round(Cost / Shares, 2) : null;
}
```

约束：

- 唯一索引 `(ledger_id, market, code)`
- `version` 并发令牌
- 数量、价格最多 4 位小数
- A 股 UI 默认整数股，允许零股/碎股
- 清仓后保留 0 股持仓，用于历史

## 3. 交易规则

### 3.1 买入

```text
成交金额 = round(数量 × 成交价, 2)
现金减少成交金额
持仓成本增加成交金额
```

界面不录入佣金 / 过户费，成交金额即现金变动金额。

- 可以首次买入自动建立持仓
- 已存在 `market + code` 时复用持仓
- 现金不足由历史重放拦截

### 3.2 卖出

```text
成交金额 = round(数量 × 成交价, 2)
现金增加成交金额
结转成本 = 持仓成本 × 卖出数量 / 卖出前数量
已实现收益 += 成交金额 - 结转成本
```

- 全部卖出时结转全部成本
- 卖出数量不能超过该业务日期时点持股
- 清仓后持仓保留为 0 股

### 3.3 录入 / 核对持仓

- 新增持仓：`StockOpening`
- 已有持仓：`StockCorrection`
- 不改变现金
- 必须提供持仓日期、数量、成本均价与当日行情（现价、行情日期由 `GET /api/ledger/stocks/quote` 自动取，不再手填）
- 成本按元 / 股录入，服务端按「股数 × 均价」折算为持仓成本总额
- 持仓日期不得早于账本起始日，也不得晚于今天；起始持仓是起始日当天的快照
- 使用 `expectedVersion` 防止覆盖并发修改

### 3.4 历史更正 / 撤销

- 股票交易进入现有历史事实体系
- 支持更正数量、金额、价格、费用、日期
- 支持撤销
- 撤销后重放自动回滚持仓、现金、成本、已实现收益
- 不提供物理删除

## 4. 今日盈亏

### 4.1 公式

设：

```text
P       最新价
P0      昨收
Q0      昨收时点持股
Q1      行情时点持股
BuyCash  区间内买入实际扣款合计
SellCash 区间内卖出净到账合计
V = P × Q1
```

则：

```text
今日盈亏 = V - P0 × Q0 - BuyCash + SellCash
```

`BuyCash` / `SellCash` 就是成交金额；界面不录入费用后费用恒为 0，历史记录里已录入的费用包含在金额中，同样不再单独扣减。

### 4.2 区间定义

- `quoteDate = position.PriceDate`
- `baselineDate = position.PreviousCloseDate`；缺失时取 `quoteDate` 的前一个 A 股交易日
- `Q0` 取 `baselineDate` 时点持股
- `Q1` 取 `quoteDate` 时点持股
- `BuyCash / SellCash` 取 `(baselineDate, quoteDate]` 区间内股票交易金额

使用行情时点持股，而不是当前持股，避免行情落后时把行情日之后的交易算进旧价格。

### 4.3 特殊情况

| 情况 | 结果 |
| --- | --- |
| 区间内有 `StockCorrection` | 该持仓今日盈亏为空 |
| 区间内有 `StockOpening` | 该持仓今日盈亏为空 |
| 缺少昨收且 `Q0 > 0` | 该持仓今日盈亏为空 |
| 缺少昨收但 `Q0 = 0` | 按 `V - BuyCash + SellCash` 计算 |
| 全部卖出 | `V = 0`，正常计算 |
| 非交易日 | 按最新行情日计算，前端显示“最近交易日盈亏” |
| 行情日期落后 | 按行情日期计算，不套用今天 |
| 刷新失败 | 保留上次昨收和价格；缺少依据时显示为空 |

### 4.4 展示口径

- `今日盈亏`：当日市场波动和交易损益
- `持仓收益`：`市值 - 成本`
- `累计收益`：`持仓收益 + 已实现收益`
- 三者独立展示，不重复相加

## 5. 历史重放与总资产

### 5.1 重放数据

- `LedgerReplayData` 增加 `Stocks`
- `ReplayResult` 增加股票持仓列表
- `KnownTotalAssets` 增加股票市值
- `Issues` 增加股票持仓日期或行情依据不足

### 5.2 重放规则

- `StockOpening`：设置持仓数量、成本、覆盖起点
- `StockCorrection`：重设持仓数量、成本
- `StockBuy`：增加数量、成本
- `StockSell`：减少数量、按比例结转成本、累计已实现收益
- `StockQuote`：只更新行情，不改变持仓
- 卖出数量不能超过该时点持股
- 允许首次买入自动建立覆盖起点
- 股票行情不是持仓变动

### 5.3 总资产

```text
总资产 =
  现金
+ 公积金
+ 基金市值 + 基金待确认 + 基金待到账
+ 积存金市值 + 积存金待到账
+ 股票市值
```

同步修改：

- 资产总览
- 资产覆盖完成判断
- 资产趋势
- 月度变化
- 资产分布
- 首页已记录资产数量
- 备份恢复

## 7. 行情

### 7.1 Provider

搜索与行情覆盖沪深北 A 股，以及沪深场内基金（沪市 `5xxxxx`、深市 `15xxxx` / `16xxxx` / `18xxxx`）；场外基金、港股、美股、债券、可转债和回购不进入搜索结果。

行情请求按站点顺序降级：主站 `QuoteProviders:StockBaseUrl`（默认 `https://push2.eastmoney.com/`）连接失败、超时或返回非 2xx 时，自动切到备用站点 `QuoteProviders:StockFallbackBaseUrl`（默认 `https://push2delay.eastmoney.com/`），字段与解析逻辑完全一致。两个站点都不通时抛出「股票行情服务暂时无法连接，请稍后重试。」并记入持仓的最近失败原因，不生成推算价格。

```csharp
public interface IStockQuoteProvider
{
    Task<ExternalStockQuote> GetLatestAsync(
        StockMarket market,
        string code,
        CancellationToken cancellationToken);

    Task<IReadOnlyList<ExternalStockSearchResult>> SearchAsync(
        string query,
        CancellationToken cancellationToken);
}
```

`ExternalStockQuote` 包含：

```text
Market, Code, Name, Price, PriceDate,
PreviousClose, PreviousCloseDate, Source
```

### 7.2 刷新规则

- 最新价或行情日期变化才写入新的 `StockQuote`
- 昨收写入持仓缓存
- 刷新失败记录 `LastQuoteError`，保留缓存估值
- 非交易日使用最近交易日收盘价
- 行情日期不能晚于今天
- 昨收无效时不影响最新价，只是今日盈亏不可用

### 7.3 调度

- `QuoteRefreshScope` 增加 `Stocks`
- `QuoteRefreshOptions` 增加 `IncludeStocks`
- `QuoteRefreshRunDto` 增加股票成功 / 失败计数
- 行情状态页增加股票来源、价格、行情日期、昨收、错误

## 8. 前端

### 8.1 入口

- 资产页维护列表
- 资产分布行
- 首页资产分布行
- 不新增底部导航

### 8.2 股票页

- 顶部：返回、股票、刷新行情
- 总览：总市值、今日盈亏、持仓收益、累计收益
- 按市场分组：沪市、深市、北交所
- 持仓行：名称、代码、数量、现价、昨收、市值、今日盈亏、持仓收益
- 详情 Sheet：持仓概览、交易记录、买入 / 卖出 / 核对
- 空状态：录入第一只股票 / 标记不持有

### 8.3 表单

- 买入：搜索、数量、成交价、业务日期、备注，预览成交金额（即扣款金额）
- 卖出：数量、成交价、业务日期、备注，预览成交金额（即到账金额）与预计收益
- 录入 / 核对：数量、成本均价（元 / 股）、自动行情行（现价 + 行情日期 + 重新获取）、持仓日期、备注

### 8.4 今日盈亏展示

- `TodayProfitDate` 等于今天：显示“今日盈亏”
- `TodayProfitDate` 早于今天：显示“最近交易日盈亏”
- 该持仓今日盈亏为空：显示 `—`
- 部分持仓不完整：合计标注“估算”
- 今日有核对：显示“今日有持仓核对，不计入当日盈亏”
