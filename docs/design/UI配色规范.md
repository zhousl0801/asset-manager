# 资产管家 UI 配色规范

版本：v1.0 · 日期：2026-10-20 · 主题标识：`porcelain`

确定方向：**瓷白底色 + 克莱因蓝**。本规范覆盖浅色界面的颜色、组件状态、财务与图表语义，可用于后续设计稿与前端实现。深色主题不在本版本范围内。

配套文件：[可复用 CSS 色彩变量](./ui-color-tokens.css)。原始色板 → 语义色 → 组件状态是统一引用顺序；组件引用语义变量，不直接散写色值。

本规范以资产总览、账户、流水、表单和报表等典型场景说明颜色用法，不调整已完成的产品功能与信息架构。收益配色默认采用“红盈绿亏”，这是本次设计约定，后续如需调整，只替换财务映射，不改成功与错误的颜色。

## 1. 视觉原则与使用面积

界面表达：清楚、克制、有秩序。让用户先看清资产与账目，再识别可执行操作。

- 瓷白是背景与留白；白色是主要内容表面；深墨色承载文字和金额。
- 克莱因蓝集中在主操作、选中标记、链接与关键数据曲线，形成品牌识别。
- 初始设计可按“中性色约 85%～90%、品牌与浅蓝约 5%～10%、状态及其他图表色少量”安排，再按页面内容调整。这是视觉检查起点，不作为像素占比验收规则。
- 首页净资产金额默认深墨色；本方案不使用整块蓝色净资产卡片。列表、表单、报表保持相同的浅色基底。
- 卡片使用纯色和轻边界；品牌渐变、蓝色发光、彩色阴影不属于本主题。
- `#002FA7` 是本产品选定的屏幕品牌色，不宣称它能等同复制实体克莱因蓝颜料在不同材质和照明下的表现。

| --- | --- | --- |
| bg-page | `#F6F7FB` | 页面底色 |
| bg-surface | `#FFFFFF` | 卡片、列表、输入框、弹窗 |
| bg-subtle | `#F1F3F7` | 分组内嵌区域、表头、只读区 |
| bg-hover | `#F5F7FF` | 行、菜单项和轻量按钮悬停 |
| bg-selected | `#EDF1FF` | 已选行、导航项、筛选标签 |
| text-primary | `#182033` | 标题、正文、重要金额 |
| text-secondary | `#626C80` | 日期、单位、说明、表格次级字段 |
| text-placeholder | `#626C80` | 输入提示；不能代替字段名称 |
| text-link | `#002FA7` | 链接、明确可操作的文字 |
| text-inverse | `#FFFFFF` | 深色背景上的文字 |
| icon-default | `#626C80` | 有意义的普通图标 |
| border-subtle | `#E2E6EE` | 装饰性分隔线 |
| border-default | `#D0D7E2` | 装饰性容器轮廓 |
| border-control | `#7A879C` | 输入框、未选复选框、开关轨道轮廓 |
| border-hover | `#626C80` | 输入类控件悬停边界 |
| focus-ring / border-focus | `#002FA7` | 键盘聚焦外环 / 输入框聚焦边界 |
| bg-disabled | `#E9EDF3` | 不可操作控件背景 |
| text-disabled | `#7B8495` | 不可操作控件文字 |
| border-disabled | `#D0D7E2` | 不可操作控件边框 |
| bg-readonly | `#F1F3F7` | 只读输入框；文字仍用 text-primary |

普通、次级、占位文字均按普通文字的对比度要求设计。不要再通过 `opacity` 减淡次级文字。层级由字号、字重、位置、留白与颜色共同表达。

金额建议使用等宽数字特性 `font-variant-numeric: tabular-nums`。金额大小、正负号、币种和小数位遵循产品数据口径，颜色不得改变金额含义。

## 4. 控件与交互状态

### 4.1 按钮

| 类型 | 默认 | 悬停 hover | 按下 active |
| --- | --- | --- | --- |
| 主按钮 | brand 背景 + on-brand 白字，无额外边框 | brand-hover 背景 | brand-active 背景 |
| 次按钮 | 白底 + brand 文字 + border-control 边框 | brand-soft 底 + brand 边框 | brand-soft-hover 底 + brand 边框 |
| 文字 / 图标按钮 | 透明底 + brand 文字或图标 | bg-hover 底 | bg-selected 底 |
| 危险确认按钮 | danger 背景 + on-danger 白字 | danger-hover 背景 | danger-active 背景 |
| 轻量危险操作 | 透明底 + danger 文字 | error-bg 底 | error-bg 底 + danger 实线轮廓 |

- 一个局部操作组通常只突出一个主按钮。危险操作确实成为当前确认流程的主任务时，使用危险确认样式。
- 所有可聚焦按钮叠加统一 focus-visible 外环，不以悬停代替键盘聚焦。
- 禁用状态：bg-disabled + text-disabled + border-disabled，取消悬停和按下反馈，并设置真实不可操作语义。不能只降低透明度。
- 加载状态：保持原按钮配色，显示“保存中…”等文字和同色加载图标，阻止重复提交；避免按钮宽度跳动。加载与禁用的视觉含义不同。
- 原生触摸操作使用按下反馈；悬停不是触摸端理解操作的前提。

### 4.2 表单、选择与开关

| 状态 | 背景 | 文字 / 图标 | 边界与附加反馈 |
| --- | --- | --- | --- |
| 普通输入 | bg-surface | text-primary；提示用 text-placeholder | border-control |
| 悬停输入 | bg-surface | 同普通 | border-hover |
| 聚焦输入 | bg-surface | 同普通 | border-focus + 统一外环 |
| 错误输入 | bg-surface | 用户输入保持 text-primary | error 实线边界 + 错误图标 + 错误说明 |
| 警告输入 | bg-surface | 用户输入保持 text-primary | warning 边界 + 警告图标 + 说明 |
| 只读输入 | bg-readonly | text-primary | border-default；仍可读取 / 复制，不套用禁用文字色 |
| 禁用输入 | bg-disabled | text-disabled | border-disabled，且真实不可操作 |
| 复选框 / 单选框未选 | bg-surface | — | border-control，保留可辨识轮廓 |
| 复选框选中 / 部分选中 | brand | on-brand 勾号 / 横线 | brand；形状区分选中与部分选中 |
| 单选框选中 | bg-surface | brand 中心圆点 | brand |
| 开关关闭 | bg-disabled | 白色滑块 | border-control 轨道轮廓 + 滑块左侧位置 + 可见“关闭”状态文字 |
| 开关开启 | brand | 白色滑块 | 滑块右侧位置 + 可见“开启”状态文字 |

复选框、单选框、开关均应用统一聚焦外环；禁用后使用禁用色并保留选中形状或滑块位置。标签文字不因控件禁用而承担解释禁用原因；原因说明另用 text-secondary 显示。

### 4.3 导航、链接与列表

- 顶部 / 底部导航：普通项 text-secondary，当前项 brand，并配合蓝色指示条、图标形态或可见下划线。使用 `aria-current` 等对应语义。
- 侧栏当前项：bg-selected + brand 图标 / 文字 + 清楚的侧边标记。不要让浅蓝背景独自承担选中识别。
- 页内选项卡：text-secondary → brand，当前项有 2px 蓝色下划线。
- 正文中的链接默认带下划线；悬停用 brand-hover；按下用 brand-active。访问后保持品牌色，本产品不借链接颜色表达账目处理状态。
- 表格 / 列表：普通白底，悬停 bg-hover，选中 bg-selected + 勾选框或明确选中标记；选中后悬停不覆盖选中底色。
- 文本选区：text-selection-bg `#DCE5FF` + text-selection-fg `#182033`。

### 4.4 状态叠加顺序

1. 禁用取消交互反馈；不显示可点击、可聚焦的假象。
2. 可操作元素保留 focus-visible 外环；错误 / 警告输入聚焦时，保留内部状态边界，外围继续使用蓝色焦点环。
3. 按下优先于悬停；选中优先于行悬停。
4. 加载保留原操作颜色；页面已有错误说明不得被加载动画遮盖。

## 5. 状态色与反馈容器

| 状态 | 主色：文字 / 图标 / 必要边界 | 浅背景 | 应用示例 |
| --- | --- | --- | --- |
| 信息 info | `#002FA7` | `#EDF1FF` | “账户余额尚未更新”、一般说明 |
| 成功 success | `#18734E` | `#EAF6EF` | “余额已更新”、导入完成 |
| 警告 warning | `#946200` | `#FFF5DF` | 待核对、数据不完整、即将到期 |
| 错误 error | `#B93838` | `#FDEEEE` | 保存失败、校验错误、已逾期 |

- 标签使用主色文字 + 对应浅底，并显示“待核对”“已完成”等状态词。
- 通知条、Toast、校验信息配对应图标与文字。较长正文可用 text-primary，状态标题与图标使用状态主色。
- 已逾期等业务风险只有在产品状态真实成立时使用错误色；普通贷款、负债余额不使用错误色。
- 警告色不采用亮黄色文字，避免浅背景上无法阅读。
- 危险操作默认 / 悬停 / 按下分别为 `#B93838` / `#A02D2D` / `#862424`，均配白字。

## 6. 财务信息的颜色口径

财务颜色与界面反馈分别建变量。即使当前颜色相同，也不能用 `success` 表示亏损，或用 `error` 表示盈利。

| 数据含义 | 对应变量 | 默认色 | 显示规则 |
| --- | --- | --- | --- |
| 投资盈利 / 正收益率 | finance-gain | `#B93838` | 如“盈利 +1,280.00”“+2.18%” |
| 投资亏损 / 负收益率 | finance-loss | `#18734E` | 如“亏损 −320.00”“−0.85%” |
| 投资盈利浅背景 | finance-gain-bg | `#FDEEEE` | 收益日历等盈利状态底色，搭配 gain 文字和正号 |
| 投资亏损浅背景 | finance-loss-bg | `#EAF6EF` | 收益日历等亏损状态底色，搭配 loss 文字和负号 |
| 持平 | finance-flat | `#626C80` | 如“持平 0.00” |
| 收入流水 | finance-income | `#18734E` | 配“收入”标签及明确方向 |
| 支出流水 | finance-expense | `#182033` | 配“支出”标签；普通支出不全部标红 |
| 内部转账 | finance-transfer | `#002FA7` | 配转出 / 转入账户与转账标识 |
| 净资产本期变化 | finance-net-change | `#182033` | 配正负号与“净资产变化”，不直接称为收益 |
| 负债本金 / 余额 | finance-liability | `#182033` | 配“负债”字段名，不因负债属性标红 |
| 缺失 / 待补数据 | text-secondary | `#626C80` | 显示“—”及“待补充”，不伪装成 0 |

附加规则：

- “红盈绿亏”为本版本默认策略；若后续支持另一种习惯，只交换 gain / loss 的财务映射，图表盈亏序列同时变化。成功绿色、错误红色保持原义。本规范不据此新增设置功能。
- 收入、支出、收益、估值调整和净资产变化是不同口径；不能仅根据金额正负选择颜色。
- 金额方向、类型标签和业务口径共同决定含义，颜色只是辅助。负号是否展示以及退款 / 冲正形式由产品数据规则决定。
- 净资产为负仍保留 text-primary 与负号；只有单独定义的风险提示采用状态色。
- 相同数值在卡片、列表、详情和导出报告中保持一致语义。

## 7. 图表配色

### 7.1 类别固定映射

| 资产类别 | 图表变量 | 色值 |
| --- | --- | --- |
| 现金与存款 | chart-cash | `#002FA7` |
| 投资资产 | chart-investment | `#6A4BC3` |
| 房产与其他实物资产 | chart-property | `#187E88` |
| 应收款 | chart-receivable | `#9B6B13` |
| 其他资产 | chart-other | `#65748D` |
| 负债类别图的总览标识 | chart-liability | `#8D4F70` |

类别不存在时不绘制，但其余类别不补位换色。负债不作为正资产构成饼图的一块；资产与负债分开表达。类别名称以正式产品分类为准，新增类别需同步分配映射与图例，不随机生成颜色。

### 7.2 指标与趋势

- 单指标趋势：主线使用 chart-net-assets / brand；可使用 brand-soft 填充辅助面积，主线和直接标注承担识别。
- 多指标趋势：净资产 `#002FA7` 实线、总资产 `#187E88` 长虚线、总负债 `#8D4F70` 点划线，同时直接标注名称；图例线型与图内一致。
- 盈亏分析图使用 finance-gain / loss / flat，并结合零基线、正负方向与数值。投资资产“类别紫色”不替代盈亏语义色。
- 同一图表的同一序列不随数值排序或选中状态换色；选中可通过加粗、点标记与说明区表达。

### 7.3 图表结构与可读性

- 图表绘图区统一 bg-surface 白底；网格 chart-grid，轴文字 text-secondary，重要标签 text-primary。
- 普通辅助网格可用浅灰；零基线、目标线等理解数据所必需的参考线使用 chart-reference，并添加“零值”“目标”等文字。
- 分类饼图、堆叠图相邻色块之间留 2px 白色分隔。类别色并非任意两两对比都达到 3:1，不能省略分隔并只依赖色相差异。
- 图例必须显示名称；重要扇区直接标注类别与数值。无法直接标注时提供可见明细表，不让信息只藏在悬停里。
- 轨道 chart-track 与主色形成进度对比；进度数值和用途同步可见，不让浅色轨道独立承载含义。
- 多序列通过文字、线型或图案辅助区分；灰度或色觉差异条件下仍能查明每条序列。

## 8. 浮层、空态、加载与遮罩

| 场景 | 背景 | 前景 / 边界 |
| --- | --- | --- |
| 弹窗、抽屉、下拉菜单 | bg-popover `#FFFFFF` | 正文 text-primary，装饰边界 border-subtle |
| Tooltip | bg-tooltip `#182033` | text-tooltip `#FFFFFF` |
| 模态遮罩 | overlay `rgba(24, 32, 51, 0.40)` | 遮罩仅覆盖背景内容；弹窗本体保持不透明 |
| 悬浮阴影 | shadow `rgba(24, 32, 51, 0.08)` | 建议 `0 8px 24px`；不作为唯一边界或状态提示 |
| 空态 | 所在页面 / 卡片背景 | 说明 text-secondary，标题 text-primary，必要操作 brand |
| 骨架屏 | skeleton-base `#E9EDF3` | 可选高亮 skeleton-highlight `#F1F3F7` |
| 加载中 | 原控件 / 原容器背景 | 可见“加载中…”说明，图标用 brand 或对应按钮前景 |

空态与加载占位不得模拟真实资产数值。骨架屏不表达数据含义，不需要靠加深颜色模拟可点击控件；减少动态偏好下使用静态骨架。

## 9. 页面套用规则

| 页面 / 区域 | 背景与金额 | 蓝色使用位置 | 特殊语义 |
| --- | --- | --- | --- |
| 资产总览 | bg-page，白色内容区，净资产深墨色 | 主操作、导航当前项、净资产趋势主线 | 本期净资产变化保持中性，收益指标才使用盈亏色 |
| 账户 / 资产详情 | 白底列表和卡片，余额 text-primary | 当前筛选、详情链接、更新操作 | 普通负债余额中性；逾期另设状态标签 |
| 流水 | 白底列表，次级日期 text-secondary | 选中筛选、转账标识、编辑操作 | 收入绿色、支出中性；退款按业务类型说明 |
| 新增 / 编辑表单 | bg-page + 白色表单区 | 主要提交、聚焦、选中控件 | 错误落在具体字段，输入金额保持正文色 |
| 报表 | 白底绘图区，深色数值 | 核心趋势线、指标切换 | 类别色与盈亏色按图表任务分别使用 |
| 设置 / 导出 | 白底分组，深色说明 | 当前项、操作入口 | 删除等真实危险操作使用 danger |

## 10. 无障碍要求与对比度验证

### 10.1 验收基线

- 普通文字与实际背景至少 **4.5:1**；包括次级文字、占位文字、图表标签、提示文字。大字可采用标准允许的 3:1，本主题默认仍按 4.5:1 设计文字。[W3C：文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
- 理解控件、状态与图形所必需的视觉部分，对相邻颜色至少 **3:1**。装饰分隔线可以较浅，不能把它当作唯一控件边界。[W3C：非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)
- 选中、盈亏、错误等均有可见的形状、文字或位置补充，不单靠颜色区别。[W3C：颜色使用](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)
- 所有键盘可操作元素有持续可见的焦点指示。项目采用 **2px brand 实线外环 + 2px 白色间隔**，以便在白底、浅灰底和蓝色按钮边缘识别；滚动容器不能裁剪焦点环。这是项目实现约定，不把该尺寸描述为 AA 条文要求。[W3C：聚焦可见](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)
- 禁用控件存在标准例外，但可读说明、只读字段和加载文字不借用禁用豁免。系统高对比度模式保留原生焦点、边界和语义，不强制关闭系统颜色适配。

## 11. 设计与开发交付规则

### 11.1 变量命名与使用

- CSS 定义集中在 `ui-color-tokens.css`，通过 `[data-theme="porcelain"]` 生效。接入时由应用入口加载该文件并在页面根节点或主题容器设置属性。
- 设计工具沿用同一层级：`palette/blue/600`、`color/bg/page`、`color/finance/gain`、`color/chart/cash`；用语义变量绑定组件实例。
- 组件写 `var(--color-brand)`、`var(--color-border-control)`；财务文字写 `var(--color-finance-gain)`，不写通用 `.red` / `.green` 类。
- 品牌、状态、财务、图表变量可暂时引用相同原始颜色，但不能因色值相同而合并其语义。
- 前景和背景成对指定。禁止对整张卡片或整个按钮使用统一透明度改变状态，避免文字与边界一起失去对比。
- 提示底色使用固定 soft 色值；遮罩与阴影才使用本规范列出的透明色。任意新增混色须重新计算实际组合。
- 本主题固定为浅色，不因系统深色模式自动反转或套用第一轮的夜间示意色。

### 11.2 最小接入示例

```html
<main data-theme="porcelain">
  <!-- 产品页面 -->
</main>
```

```css
.asset-page {
  background: var(--color-bg-page);
  color: var(--color-text-primary);
}

.asset-primary-action {
  background: var(--color-brand);
  color: var(--color-on-brand);
}

.asset-primary-action:hover:not(:disabled) {
  background: var(--color-brand-hover);
}

.asset-primary-action:active:not(:disabled) {
  background: var(--color-brand-active);
}

.asset-control:focus-visible {
  /* 白色间隔确保蓝色按钮周围也可看清蓝色外环。 */
  outline: 2px solid var(--color-focus-ring);
  outline-offset: 2px;
  box-shadow: 0 0 0 2px var(--color-focus-gap);
}
```

以上只演示变量接入与焦点环；组件仍须实现对应禁用语义、状态表、尺寸和交互。所有可聚焦组件都应获得等价焦点样式，不只限于示例类名。

### 11.3 页面验收清单

- [ ] 页面以瓷白背景、白色内容区和深色金额为主，品牌蓝集中使用。
- [ ] 颜色来自统一变量；没有不明用途的第二套品牌蓝、任意红绿或透明文字。
- [ ] 主操作、输入框、选择控件覆盖适用的普通、悬停、按下、选中、聚焦、加载、只读与禁用状态。
- [ ] 错误 / 警告字段保留文字说明；聚焦时仍能识别原状态。
- [ ] 键盘焦点清晰、未被容器或覆盖层裁剪；触摸端无需依赖悬停。
- [ ] 盈亏、收入支出、转账、净资产变化和负债使用各自语义，不混淆口径。
- [ ] 图表映射固定；色块有分隔，序列有标签 / 线型，核心数据有可见文字途径。
- [ ] 实际组件、叠加背景和新增颜色组合达到对应对比度；禁用与装饰例外未扩大到正常内容。
- [ ] 典型页面在灰度、色觉差异模拟及系统高对比度环境下仍可识别核心状态。
