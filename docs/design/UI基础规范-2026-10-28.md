# UI 基础规范 P0 · 2026-10-28

本轮只处理“像不像原生 App”的基础层，不改变业务信息架构。目标是把字号、点击尺寸、圆角、动效和 PWA 外观从各页面局部值收回到统一 token。

## 1. 文本层级

新增 `web/src/styles/tokens.css`，正文和说明文字不再使用 9–11px。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--text-caption` | 12px | 标签、日期、图表轴、辅助说明 |
| `--text-footnote` | 13px | 次要信息、表单提示 |
| `--text-subhead` | 15px | 列表主文本、设置行 |
| `--text-body` | 16px | 正文和输入 |
| `--text-headline` | 17px | 页面内标题 |
| `--text-title3` | 20px | 区块标题 |
| `--text-title2` | 22px | 页面标题 |
| `--text-title1` | 28px | 一级页面大标题 |
| `--text-large-title` | 34px | 首页/设置类大标题 |
| `--text-display` | 40px | 资产主金额 |

规则：

- 正文不低于 15–16px，说明文字不低于 12px；图表轴和徽标最低 12px。
- 字重只使用 400 / 500 / 600 / 700，不再使用 550 / 650 这类合成字重。
- 金额继续使用 `font-variant-numeric: tabular-nums`。
- 大标题与主金额保留少量负字距，正文不使用负字距。

## 2. 间距与圆角

| Token | 值 |
| --- | --- |
| `--space-1` ~ `--space-6` | 4 / 8 / 12 / 16 / 24 / 32px |
| `--page-gutter` | 20px |
| `--card-padding` | 16px |
| `--radius-tag` | 6px |
| `--radius-control` | 10px |
| `--radius-card` | 14px |
| `--radius-sheet` | 24px |
| `--radius-pill` | 999px |

通用页面左右边距统一为 20px；记一笔全屏键盘页保留 16px。卡片、控件、标签和 sheet 不再各自声明 7/8/9/12/13/16px 等圆角。

## 3. 点击尺寸

`--touch-target: 44px`。返回按钮、底部 sheet 关闭、趋势范围、日历前后月、资产行操作、基金分组 chip、安全操作、账本周期与筛选控件均补到至少 44×44。

保留的例外：

- 分类图标本身是视觉元素，整块分类 tile 的可点击区域大于 44px。
- 底部导航由整格承担点击，不要求图标本身 44px。
- 图表 canvas 的点击由图表坐标系承担，轴标签不作为独立点击目标。

## 4. BottomSheet

`web/src/components/BottomSheet.vue` 已补齐：

- 遮罩淡入 + 面板上滑，使用 `--motion-sheet` 与 `--ease-sheet`。
- 顶部 grabber，可按住下滑关闭；超过 96px 触发关闭。
- 打开后焦点进入对话框，Tab / Shift+Tab 在对话框内循环，关闭后回到触发元素。
- 不再自动聚焦第一个输入框，避免打开即弹键盘。
- `Escape` 关闭，背景滚动锁定。
- 全局 `prefers-reduced-motion` 下关闭动画。

## 5. 导航

- 底部导航选中态使用 filled 图标，未选中使用 outline 图标。
- 中央“记一笔”保留为品牌化全局操作：独立圆形、`aria-label`、明确主操作视觉；它不是普通 tab。
- 导航标签提升到 12px，触控区域随 tab 整格。

## 6. PWA 外观

- `theme-color` 改为与顶部栏一致的白色，避免 iOS / Android 状态栏蓝白割裂。
- 增加 iOS `apple-mobile-web-app-*` meta 和 180×180 `apple-touch-icon`。
- manifest 增加 192 / 512 PNG、maskable 图标与竖屏方向。
- 图标源文件为 `web/public/icons/icon-source.svg`，生成文件随前端构建同步到 API 的 `wwwroot`。

## 7. 确认与反馈

- 删除 Passkey、删除投资分组不再使用 `window.confirm`，统一使用 `ConfirmSheet`：底部弹出、可取消、危险按钮使用 danger 语义。
- 内部说明性文案（例如“首版只提供……”）从用户界面移除。

## 8. 图表

- ECharts 颜色集中到 `web/src/utils/chartTheme.ts`，与 `docs/design/ui-color-tokens.css` 的语义值对应。
- 图表轴文字提升到 12px；首页趋势移除最高/最低浮动标签，避免 320px 下右侧裁切，读数由上方选点区域承担。

## 9. 仍留给 P1 的事项

- 首页、记一笔、投资页的信息层级重排。
- 表单/列表统一为 inset grouped list。
- 路由转场、toast、骨架屏。
- 桌面端设备画布或双列布局。
- 深色模式与 Dynamic Type。

## 10. P1 进展

2026-10-28 已完成第一批页面层级重构：

- 首页：大标题「总览」、日期、主金额、变化 pill 和更清楚的区块标题；资产行增加进入箭头。
- 记一笔：金额优先，分类改为横向 chips，键盘改为无边框大按键。
- 计划：交易日历移到计划与执行记录之后，首屏先展示计划。
- 资产：未录入资产增加录入提示卡，已录入资产行明确可进入详情。
- 投资：搜索、排序、指标收进右上角筛选 sheet，减少首屏折叠行。
- 加载：首页、账本、投资增加骨架屏。
- 桌面：600px 以上使用圆角设备画布，避免手机列悬浮在空白背景中。
- 全局：路由淡入转场、滚动位置复位。

仍未完成：投资页更彻底的信息分区、资产页完整核对流程、深色模式与 Dynamic Type。
