## 阅读与维护约定

- 业务范围与财务口径以产品设计为准，技术与视觉文档不自行扩展业务。
- UI 规范中的通用示例可能提及首版未包含的类别；实现时以产品设计确定的现金、基金、公积金、积存金为准。
- 文档、图片与原型使用仓库内相对链接；临时预览会话地址不作为长期入口。
- 线框与截图是设计参考，原型是静态演示；它们均不构成正式持久化、真实行情或自动任务的验收证据。
- 后续自然语言记账记录在技术选型第 6.1 节，尚未纳入首版必交范围。
- 开发记录按日期归档，只记录当日实际实现与验证结果；业务口径与未完成边界仍以产品设计和当前代码为准。

归档时保留产品设计的业务正文与原型交互代码，仅修正文档组织、可迁移链接和当前阶段说明。原会话目录的源文件仍保留；仓库内文档作为后续维护入口。
