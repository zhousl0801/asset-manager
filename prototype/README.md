# 资产总览高保真原型

以已确认的《资产管家 · 产品设计文档 V1.0》及其最终整合线框为依据。本原型是手机端 Web 演示，桌面浏览也展示手机画幅；正式应用已选定响应式 Web App / PWA，桌面适配尚未实现。

## 设计依据

- 产品文档：[产品设计 V1.0](../docs/product/资产管家-产品设计文档-V1.0.md)。
- 最终整合线框：[仓库内归档](../docs/design/wireframes/index.html)。
- 配色：[UI 配色规范](../docs/design/UI配色规范.md)与[CSS 变量](../docs/design/ui-color-tokens.css)。业务含义以产品文档为准，不采用配色规范早期示例中的净资产、房产、负债和多现金账户。

首页顺序：总资产与本月变化 → 总资产趋势 → 现金 / 基金 / 公积金 / 积存金 → 本月收支 → 近期自动记账。底部保留“总览 / 账本 / ＋记一笔 / 投资 / 我的”。

`index.html` 保留最终线框的应用页面结构；`app.js` 复用原页面内演示交互，仅移除设计评审面板逻辑并将初始页改为首页；`wireframe.css` 保存原线框基础样式；`styles.css` 是本次视觉覆盖层。四类资产入口、记一笔和计划等目标页保留线框演示，未声明为全产品高保真交付。

## 本地预览

在项目根目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173/prototype/>。

## 演示边界

初始现金 23,400、基金 168,000（含待确认 300）、公积金 68,000、积存金 27,000（30 克），合计总资产 286,400。本月变化 11,800 = 生活结余 5,200 + 公积金缴存 5,200 + 投资盈亏 1,400。

所有数值与记录均为原设计的虚构示例。保留原线框的页面内联动、计划预览和示例趋势；刷新重置。没有后台服务、数据库写入、真实行情、识别、自动任务或实际金融操作。浏览器演示不替代产品文档的正式验收要求。
