# 资产总览高保真原型

以已确认的《资产管家 · 产品设计文档 V1.0》及其最终整合线框为依据。本原型是手机端 Web 演示，桌面浏览也展示手机画幅；正式应用已选定 Web App / PWA，本阶段只迭代手机版本，独立桌面布局留待后续评估。

## 设计依据

- 产品文档：[产品设计 V1.1](../docs/product/资产管家-产品设计文档-V1.1.md)。
- 最终整合线框：[仓库内归档](../docs/design/wireframes/index.html)。
- 配色：[UI 配色规范](../docs/design/UI配色规范.md)与[CSS 变量](../docs/design/ui-color-tokens.css)。业务含义以产品文档为准，不采用配色规范早期示例中的净资产、房产、负债和多现金账户。

首页顺序：已记录资产与同口径本月变化 → 已记录资产趋势（记录满 7 天后显示） → 资产分布（比例条 + 统一行结构） → 本月收支 → 近期自动记账。底部为“总览 / 资产 / 账本 / 我的”四项，记一笔入口移到头部 ＋。完整记录之前只显示“已记录资产”，新增记录单列且不计入本月变化。

`index.html` 保留最终线框的应用页面结构；`app.js` 复用原页面内演示交互，移除设计评审面板逻辑并将初始页改为首页，图表与动态内容引用统一颜色变量；`wireframe.css` 保留线框布局并统一接入语义色；`styles.css` 提供首页视觉细化和共享主题样式。账本、记一笔、投资及详情、四类资产和计划页面共用瓷白与克莱因蓝主题，盈亏与收支保留独立的财务颜色。首页之外仍保留线框布局，统一配色不代表全产品已完成高保真设计或正式功能开发。

## 本地预览

在项目根目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173/prototype/>。

## 演示边界

初始现金 23,400、基金 168,000（含待确认 300）、公积金 68,000、积存金 27,000（30 克），合计 286,400，已记录 4 类。本月变化 11,800 = 净存入·转账 10,400（生活结余 5,200 + 公积金缴存 5,200）+ 市值变动 1,400；新增记录为 0，单独列出不计入变化。

所有数值与记录均为原设计的虚构示例。保留原线框的页面内联动、计划预览和示例趋势；刷新重置。没有后台服务、数据库写入、真实行情、识别、自动任务或实际金融操作。浏览器演示不替代产品文档的正式验收要求。
